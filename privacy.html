Privacy Policy

Effective date: September 24, 2026

Personal Ops Backup is a private, single-owner automation. It is not offered to the public and does not provide user registration.

Data accessed

The application accesses Google Drive file metadata and file content only as needed to perform a read-only export requested by the owner.

Purpose

Accessed data is used only to create the owner's backup and an approved local reference subset.

Processing and storage

Processing takes place on an owner-controlled Windows PC. Exported data is stored only in owner-controlled local storage. The application does not operate a public application server.

OAuth credentials and tokens are stored locally on the owner-controlled PC and are not published by this website.

Sharing and advertising

Data accessed through Google Drive is not sold, used for advertising, or shared publicly. This website uses no analytics, advertising, forms, cookies set by the application, or client-side JavaScript.

Retention and deletion

The owner controls the retention and deletion of exported data and may revoke the application's Google Account access at any time.

Service providers

The application uses the Google Drive API for read-only access. GitHub Pages hosts this static policy website and may process standard web request information under GitHub's own privacy practices.

Contact

Contact the operator through the elian-personal-work organization profile.
